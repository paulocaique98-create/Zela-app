## Problema investigado
Cadastro de usuário no perfil Marketing (ex.: raiza@onfilmes.com.br) pela Gestão dava "Edge Function returned a non-2xx status code".

## Causa encontrada
`escola_liberada()` só tem EXECUTE para `service_role` (migration 20261210120000). Três Edge Functions chamavam `exigirEscolaLiberada` com o client do usuário (chave anon), então a RPC era recusada e a função devolvia HTTP 400 "Não foi possível confirmar o acesso da escola" para qualquer chamador que não fosse developer.
