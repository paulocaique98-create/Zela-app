# Capturas da App Store (iOS)

Os arquivos `rascunho-*` foram gerados em 13/10/2026 com o app web da homologação num viewport de iPhone 6,9" (440x956 a 3x = 1320x2868), dados fictícios. São só rascunhos de composição.

Para enviar à Apple, refazer a partir do app instalado no iPhone (TestFlight): a Apple espera capturas do app real. Tamanhos: 6,9" (1320x2868) e 6,5" (1242x2688 ou 1284x2778). Roteiro em `PREPARACAO_LOJAS.md`, seção 4.1.
